# Знакомство с GitHub

Одностраничный сайт-объяснение основ Git и GitHub: репозитории, коммиты, ветки, pull request-ы, базовые команды и первые шаги.

Чистый HTML/CSS/JS, без сборки и зависимостей — открывается напрямую в браузере.

## Как запустить локально

Просто откройте `index.html` в браузере — ничего устанавливать не нужно.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите в него файлы этого проекта:
   ```
   git init
   git add .
   git commit -m "первый коммит: сайт про GitHub"
   git branch -M main
   git remote add origin https://github.com/ваш-логин/название-репозитория.git
   git push -u origin main
   ```
2. На GitHub откройте репозиторий → **Settings → Pages**.
3. В разделе **Build and deployment** выберите источник **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Через минуту сайт станет доступен по адресу:
   `https://ваш-логин.github.io/название-репозитория/`
